社会マスター v9.4（TOP設定画面版）

【GitHub Pagesへの更新方法】
ZIPを展開し、中にあるファイルを geography-quiz リポジトリのルートへ上書きしてください。公開URLは変わりません。

【v9.4の主な変更】
・TOP右上に歯車の設定ボタンを追加
・記述に挑戦する前でも、設定画面から親用4桁暗証番号を登録可能
・暗証番号の設定状態と承認待ち件数を表示
・暗証番号の変更時は現在の暗証番号を確認
・設定画面から記述の承認管理、バックアップ保存・読み込みを実行可能
・v9.3の学習履歴、称号、承認状態、親用暗証番号をそのまま引き継ぎ

【v9.3から継続する親承認機能】
・記述全問○は即時制覇せず「親の承認待ち」に変更
・初回に親用4桁暗証番号を設定
・親の確認画面で承認、却下、承認取消
・承認時に記述制覇、極称号、最高ランクを反映
・取消時に記述制覇数、極称号、最高ランクを再計算
・親の承認・却下・取消履歴を端末内に保存
・v9.2までの承認済み記述制覇は維持

【v9.2から継続するランク表示】
・TOPの現在ランク表示をコンパクト化
・「日本地理 攻略ランク」を押すと攻略詳細を開閉
・初期状態では前期・夏期の制覇数、攻略マーク、最高記録を折りたたむ

【v9.1から継続する夏期講習機能】
・夏期講習を北海道・東北／関東／中部／近畿／中国／四国／九州・沖縄の7地域から複数選択
・夏期講習で1地域だけを選んだ全問チャレンジを称号対象に追加
・夏期7地域それぞれに4択称号と記述極称号を追加
・夏期4択7地域制覇で「七地方の覇者」
・夏期4択・記述7地域完全制覇で「極・七地方の覇者」
・TOPに前期17単元と夏期7地域の攻略状況を表示
・最高位「真・社会マスター」は前期17単元と夏期7地域の完全制覇が条件

【v9から継続する攻略機能】
・単元1～17の4択／記述の制覇判定と最高記録
・単元固有称号、総合ランク、TOP攻略カード
・称号獲得、極称号、ランクアップ演出
・1単元だけを選んだ全問チャレンジのみ制覇判定
・通常の20問／50問、複数単元・複数地域、全範囲、復習は制覇判定の対象外

【v8から継続する記述機能】
・4択モードと記述モードを選択可能
・記述では選択肢を表示せず、紙やノートに書いてから「答えを見る」
・本人が○／△／×で自己判定
　○：漢字まで正しく書けた
　△：答えは分かったが、漢字・表記を間違えた
　×：思い出せなかった
・記述は10問、20問、選択範囲の全問から選択
・4択と記述の学習履歴を分けて表示
・記述の○、△、×を独立して保存
・△と×の問題だけを再挑戦可能
・記述でも教材と前期単元1～17を選択可能

【継続して使える機能】
・夏期講習139問と小4前期450問（合計589問）
・小4前期、夏期講習、全範囲の選択
・前期単元1～17の複数選択
・4択の20問、50問、全問チャレンジ
・正解・不正解の効果音、ON/OFF、音量調整
・誤答一覧と復習
・端末内の過去100回分の履歴
・セーブデータ（履歴・設定・称号・ランク・最高記録）のバックアップ保存／読み込み
・PWA、オフライン対応

【データと保存】
問題データと従来の保存キーは変更していません。
学習履歴：social-quiz-progress-v1
設定：social-quiz-settings-v1
v5、v6、v7の履歴・設定をそのまま引き継ぎます。旧履歴は4択の記録として表示します。
攻略データ：social-quiz-mastery-v1
今後、ホーム画面アイコンを追加し直す場合や端末を変更する場合は、変更前に「バックアップを保存」、変更後に「バックアップを読み込む」を使用してください。前期・夏期の称号、ランク、最高記録もバックアップに含まれます。
