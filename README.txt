地理ランダムクイズ PWA版

GitHub Pagesへ、このフォルダ内の5ファイルをそのままアップロードしてください。

・index.html
・manifest.webmanifest
・sw.js
・icon-192.png
・icon-512.png

GitHub Pages公開後、スマホで公開URLを開きます。

iPhone / iPad:
Safari → 共有 →「ホーム画面に追加」

Android:
Chrome → メニュー →「ホーム画面に追加」または「アプリをインストール」

一度読み込めば、Service Workerのキャッシュによりオフラインでも利用できる構成です。
