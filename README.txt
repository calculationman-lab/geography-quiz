【使い方・称号】
TOPの出題範囲「小4下期・前半」から単元を選んでください。
4択は正答1個＋誤答5候補から、誤答3個を抽出して4択表示します。
記述は紙に書いてから答えを表示し、○・△・×で自己判定します。
単元を1つだけ選び「全問チャレンジ」で全問正解すると、その単元の4択称号を獲得します。
通常の20問ボタンでは、出題数が同じ20問でも称号判定をしません。
複数単元・全範囲・復習も称号判定の対象外です。
記述全問○は親の承認待ちになり、承認後に記述制覇へ反映されます。
4択・記述の両方を制覇すると「極・」称号になります。
下期の7個の単元アイコンはTOPの攻略ランク詳細に追加しています。
下期称号は独立した追加要素です。既存のランク条件を増やして降格させる変更はしていません。
夏期の王冠「7地域」アイコンもそのまま残しています。

1. 現在のアプリの「⚙ 設定 → バックアップを保存」を実行。
2. iPadの「ファイル」アプリで、保存したJSONを開ける場所にあることを確認。
3. ZIPを展開し、中身を既存 geography-quiz リポジトリの公開ルートへ上書き。
   social_v11というフォルダを1段追加するのではなく、index.htmlが従来と同じ場所になるようにします。
   lower-questions.jsは今回の新規ファイルです。必ずほかのファイルと一緒に追加してください。
4. GitHub Pagesの更新が完了したら、これまでと同じURL・ブラウザーで再読み込み。
5. TOPの「更新版 v11.0」、下期140問、これまでの履歴・称号を確認。

このZIPを作成しただけではGitHubへは公開されません。リポジトリへの上書きは利用者側の操作です。
古い表示が残る場合は、まずアプリを閉じて開き直してください。
バックアップを確認するまで、SafariのWebサイトデータ削除やアプリの削除はしないでください。
記録が見えない場合は、URL・ブラウザーが以前と同じか確認し、必要なら設定からJSONを読み込んでください。
