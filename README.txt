【v8から継続する記述機能】
・4択モードと記述モードを選択可能

・本人が○／△／×で自己判定

　△：答えは分かったが、漢字・表記を間違えた

・4択と記述の学習履歴を分けて表示
・記述の○、△、×を独立して保存
・△と×の問題だけを再挑戦可能
・記述でも教材と前期単元1～17を選択可能
