小4社会 学習クイズ v6（4択・自動採点版）

【GitHub Pagesへの更新方法】
ZIPを展開し、中にあるファイルを geography-quiz リポジトリのルートへ上書きしてください。
公開URLは変わりません。

【v6の主な変更】
・夏期講習139問と小4前期450問を統合（合計589問）
・出題範囲を「小4前期」「夏期講習」「全範囲」から選択
・選択範囲ごとに20問、50問、範囲内全問を選択
・前期問題に単元1～17の内部タグを設定
・クイズ画面に教材、単元、地域を表示
・同じ回の中では同一問題を重複出題しない
・履歴に選択した出題範囲を保存
・v5までの履歴と効果音設定を引き継ぐ

【継続して使える機能】
・問題ごとに選定した、混同しやすい4択
・正解・不正解の効果音、ON/OFF、音量調整
・自動採点、正答率、所要時間
・誤答一覧と誤答だけの復習
・端末内の過去100回分の履歴
・今日の実施状況
・PWA、オフライン対応

【データと保存】
問題は questions.js、出題・採点は app.js、画面は index.html、デザインは styles.css に分離しています。
学習履歴は従来どおり localStorage の social-quiz-progress-v1 に保存します。
効果音設定は social-quiz-settings-v1 に保存し、v6では最後に選んだ出題範囲も同じ設定へ追加します。
復習では本番履歴を追加しません。
